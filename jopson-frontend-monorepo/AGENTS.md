# Jopson 前端工程规范

本文件继承[仓库工程规范](../AGENTS.md)。安装、启动、构建和后端联调见[前端 README](README.zh-CN.md#安装使用)。

## 应用和公共包

- 后台站点的视图、路由、权限入口、API 和 Antdv Next 适配归 `apps/jopson-admin-web/src`。跨页面的列表约定由[应用表格适配器](apps/jopson-admin-web/src/adapter/vxe-table.ts)提供。抽屉和编辑表单复用同一组件库，按各自用例组织。
- `packages` 维护可复用组件及运行时能力。多个消费者需要同一行为，或现有公共实现有可复现的问题时，才修改相应公共包；变更须覆盖已有调用方式。`internal` 和 `scripts` 负责构建与开发工具。依赖以 pnpm 工作区和锁文件为准。
- 新增能力前检查已有的 Vue、Pinia、Vben 和 Antdv Next 封装。字典、导出、持久化列设置及权限操作等，随真实业务和后端契约接入。

## 业务域和接口

- 将视图按 `views/<业务域>/<业务对象>` 组织，在对应的 `api/<业务域>/<业务对象>` 维护请求函数和模型。查询、创建、修改、状态命令分别对齐后端允许提交的字段，列表行和详情按消费场景定义。检查实际 Controller 的路径、方法和媒体类型。
- JSON 响应通过现有请求客户端解包 `code/message/data`，成功码为 0。分页请求使用 `currentPage/pageSize`，结果读取 `items/total/currentPage/pageSize`，首次查询默认第 1 页、每页 20 条。纯文本与文件走各自的响应处理。
- 页面分别呈现加载、成功、空数据、错误和无权限。写入成功以后再更新列表或提示完成；提交过程中防止重复操作。筛选变化时回到第一页，翻页沿用已提交的条件。并发查询只展示最新有效结果，卸载时清理订阅和在途工作。
- 前端权限控制菜单、路由和操作入口，对象可访问范围由后端判定。登录失效沿用已有请求及路由处理，保留返回地址。客户端环境变量、日志和持久化偏好中避免写入服务端凭据。

## 标准列表与表单

- 全页列表使用 `Page` 和应用的 `useVbenVxeGrid`。查询条件在 `formOptions` 定义；工具栏主操作、刷新、列工具、行操作和分页分别放在对应插槽或组件。
- 默认查询网格随视口显示 1、2、3、4 列。首次折叠为一行，宽屏普通字段占前三格，查询、重置及展开按钮占最后一格。显示不全时提供展开／收起；字段跨列后按实际空间计算，展开与收起均保留输入值。
- 表单外层列数用 `wrapperClass`，字段跨列用 `formItemClass`（如 `md:col-span-2`）。`commonConfig.wrapperClass` 只控制字段内部。窄分栏、弹窗、抽屉按内容宽度显式配置列数。操作区默认 `rowEnd`；页面可覆盖列数、初始折叠状态和行数。
- 表头、内容默认左对齐，同类字段保持一致。金额等业务列可显式覆盖。选择列默认 48px、序号列默认 56px；日期和日期时间列建议分别预留 110px、170px。普通列优先 `minWidth`；操作列按可见按钮、文字和间距定宽，避免换行。
- 查询字段保留可见标签、清晰的焦点和自然的 Tab 顺序，图标按钮具有可访问名称。给普通输入启用回车查询时，分别验证下拉选择、日期输入及文本域的键盘行为。布局区分空值与有效的 `0`、`false`，状态同时以文字或图标表达。

## 验收

布局改动用真实表单、表格和分页测试。在窄屏、平板、1280、1440、1920px 及侧栏两种状态下核对字段位置、按钮占位、长标签和横向溢出。验证展开切换保留输入，记录查询、重置和翻页产生的请求次数及参数。测试页使用独立入口，业务路由只注册正式页面。
