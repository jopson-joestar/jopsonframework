# 公共技术能力

本目录继承[仓库工程规范](../../AGENTS.md)。core 作为普通 JAR 供各站独立引用，负责跨业务契约、Spring 集成和基础设施适配。账号、角色、菜单和单据流程由相应业务域拥有。

## 能力、依赖与装配

- 按能力组织包，技术实现、配置及其测试放在同一能力下。公共响应、分页、异常、JSON 和请求标识各有一个定义源，消费方复用公开契约。简单操作用 JDK，通用工具优先复用已引入的 Hutool Core。HTTP 模型沿用 Boot 管理的 Jackson 配置。
- 依赖与插件版本由 [jorsy-starter-parent](../pom.xml) 及其引入的 BOM 管理，在承担能力的模块声明所需依赖。Lombok、MapStruct 处理器及其绑定留在编译期。调整映射工具链时，用含 Lombok 属性的对象验证生成、Spring 注入及字段值，检查站点可执行 JAR 的库清单。
- 自动配置使用 `@AutoConfiguration` 并登记在 `AutoConfiguration.imports`。Servlet、类路径、属性及可替换 Bean 按实际启用条件装配，消费方能使用自己的包扫描范围和 Bean。启动早期的环境默认值使用 Boot 对应的扩展入口，保留站点显式配置的优先级。
- 优先复用 `spring.cache.*`、`springdoc.*`、`management.*` 等原生配置。新增适配写明最小依赖、默认值、启用条件和关闭方式。客户端由容器管理，明确创建和释放时机。普通 MVC 消费方须能在没有数据库、Redis 或注册中心的环境中启动。

## 契约与验收

- JSON 改动经真实 MVC 请求验证日期读写、偏移及十进制精度。异常响应核对业务码、HTTP 状态和必要响应头。日志核对 `X-Request-Id`、MDC、异步传递及线程复用后的清理。
- 缓存变更验证重复读取、失效、可控时钟下的过期和消费方覆盖。指标采集、健康检查与管理端点开放分别配置。验证默认健康入口与敏感端点的可见性。开发文档默认关闭，由站点选择开启环境。
- 自动配置改动用适用的默认、启用、关闭、缺少可选依赖和自定义 Bean 场景验证。Web 测试从不同根包启动仅引用 core 的站点，核对公共能力以及后台路由的隔离。当前 HTTP 契约可从 [CoreWebTest](src/test/java/org/example/jorsy/CoreWebTest.java) 查起。
